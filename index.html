Department of Dravyaguna
Kashtadaru
Botanical Name :

  • Polyalthia longifolia Thwaites

    • Family Name :

  • Annonaceae

    • Local Name :

  • Kastadare (Kannada)

    • Vernacular Name :

  • Hindi – Ashok / Devdaru Ashok

  • English – Mast Tree

    • Synonyms :

  • Kashtadaru

  • False Ashoka

  • Mast Tree

    • Habitat :

  • Native to Sri Lanka and widely cultivated throughout India as an ornamental avenue tree in gardens, parks and educational institutions.

    • External Morphology :

  • Height : Evergreen tree, 10–20 m tall.

  • Leaves : Simple, alternate, long, narrow, shiny green with wavy margins.

  • Flowers : Small, greenish-yellow, fragrant, borne in clusters.

  • Fruit : Small, ovoid berries turning purple-black on ripening.

  • Bark : Smooth, grey to brown.

    • Useful Parts :

  • Bark

  • Leaves

  • Seeds

    • Rasadi Panchaka :

  • Rasa: Tikta, Kashaya

  • Guna: Laghu, Ruksha

  • Virya: Sheeta

  • Vipaka: Katu

    • Pharmacological Action :

  • Antipyretic

  • Anti-inflammatory

  • Antimicrobial


    • Therapeutic Administration :

  • Fever: Bark decoction is administered traditionally.

  • Skin Diseases: Bark paste is applied externally.

  • Helminthiasis: Bark and leaf preparations are used traditionally.

  • Wounds: Leaf paste is applied over affected area.

    • Dose :

  • Churna (Powder) : 3–6 g

  • Kwatha (Decoction) : 50–100 ml

    • Formulations :

  • Bark Decoction (Kwatha)

  • Leaf Paste

  • Traditional Herbal Preparations
